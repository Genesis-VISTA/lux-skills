# Lux GRPO smoke baseline, 2026-10-27

These are measured training runs from this skill's hand-run wrapper on eight Lux nodes (64 MI355X GPUs), using the world-shared variant A image, Mistral-Large-Instruct-2411 model, and `rl_control.parquet`. Both used `RL_DIST_TIMEOUT_MIN=90`, `RL_SAVE_FREQ=-1`, `RL_TEST_FREQ=-1`, and `RL_VAL_BEFORE=False`. No checkpoint or held-out evaluation was produced. `critic/score/mean` is the training batch's verifiable reward, not held-out accuracy.

The jobs read the original Lux AI-for-Science package. The skill now defaults to `Genesis-Hackathon`: its existing Mistral model has matching manifest hashes, and the copied image and prepared data passed full content comparisons with the original. This baseline is a reference for those same inputs; it is not a separate run from the new path.
